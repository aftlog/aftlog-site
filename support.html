Troubleshooting

App won't install or update?

Make sure you're installing the signed AftLog APK and that 'Install unknown apps' is allowed for your file manager.

GPS not tracking?

Grant location permission when the app asks — AftLog uses it only for trip tracking you start yourself.

Reminders not firing?

Check notification permission and ensure the app isn't force-stopped by your battery saver.

AI assistant offline?

The assistant needs a connection to the AftLog server; without one it uses on-device guidance.

Backup / restore?

Use More → Backup to export a JSON file — keep it somewhere safe.
