Using float plan

Tell someone where you're going — fast.

Steps

  1. Open More → Tools → Float Plan.
  2. Enter destination, route, and return time.
  3. Share the plan via text.
  4. Cancel the plan when you're back.

Tips

  • A float plan is one of the best safety habits.
  • Packs a GPS share if you need help.
